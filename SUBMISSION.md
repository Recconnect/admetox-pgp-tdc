# TDC Submission Metadata

## Benchmark

- Benchmark group: ADMET Group
- Endpoint: `Pgp_Broccatelli`
- Task: binary classification
- Metric: AUROC
- Split: official TDC scaffold split (973 train_val / 245 test)

## Model

- Name: ADMETox GINE20 + MapLight GBM15
- Formula: `0.75 * GNN20 + 0.25 * GBM15`
- GNN: six-layer GINE, hidden size 256, dropout 0.08, five-fold training, 20 seeds per run
- GBM: equal CatBoost (ss=0.5) + LightGBM + XGBoost ensemble on MapLight 2580d features, 15 seeds
- Independent runs: 5
- Source: https://github.com/Recconnect/admetox-pgp-tdc

## Result

Generated by `python run_pgp.py` (reproduce mode) and copied from `output/pgp_results.json`.

- Individual AUROCs: `0.9399, 0.9396, 0.9401, 0.9403, 0.9397`
- Mean / std: `0.9400 +/- 0.0003`
- TDC `evaluate_many`: `0.940 +/- 0.000` (TDC rounds mean/std to 3 decimals)
- Current TDC leader: `0.938 +/- 0.002` (MapLight + GNN)
- Gap: `+0.0020` — **BEATS SOTA**
- Run 1 reproduces the published frozen ensemble: official-test AUROC `0.9399`

## Reproduction

```bash
python install.py
python run_pgp.py
```

The default command reproduces `output/pgp_results.json` deterministically from the committed per-seed predictions (`assets/pgp_legs.npz`). Full end-to-end retraining of every model is available via `python run_pgp.py --mode train`.
